MoneyMap

MoneyMap is a personal finance tracking web application developed using ASP.NET Core 10 MVC.
The application is designed to help users efficiently manage, track, and analyze their personal 
expenses through a secure and intuitive interface.

MoneyMap offers a robust platform for expense tracking, featuring secure user authentication, 
comprehensive expense management, and a clean, data-driven dashboard. The system enables users 
to monitor spending patterns, maintain accurate financial records, and gain better control over their personal finances.


## Features

- **User Authentication**  
  Secure user registration and sign-in using ASP.NET Core Identity

- **Expense Management**  
  Create, view, and manage personal expense records

- **User Dashboard**  
  Centralized overview of expense data for authenticated users

- **Responsive Design**  
  Fully responsive interface optimized for desktop and mobile devices

- **Real-Time Validation**  
  Client-side form validation to enhance usability and data accuracy

## Technology Stack

- **ASP.NET Core 10 MVC**  
  Modern, high-performance web framework for building scalable applications

- **Razor Pages**  
  Server-side UI rendering for clean and maintainable views

- **Entity Framework Core**  
  Object-relational mapper (ORM) for database access

- **ASP.NET Core Identity**  
  Built-in authentication and authorization framework

- **Database Support**  
  Compatible with multiple database providers via Entity Framework Core, including SQL Server, PostgreSQL, and SQLite
